# Моделирование разбавленных магнетиков: SDEM, кинетическая модель, нейросети

Проект исследовательский (магнитные наночастицы в немагнитной матрице: стёкла, обожжённые глины, композиты). Цель: тезисы и статьи, где ML и численные модели используются там, где они реально лучше аналитики. SDEM (модель Харитонского, Сетрова, Ралина) считается рабочей основой, а не объектом критики.

## Главные идеи (что мы делаем и зачем)

1. **Байесовская надстройка над SDEM** (`sdem_mcmc/`). Формулы SDEM используются как прямая модель, MCMC даёт интервалы для параметров и показывает, что определено данными, а что допущениями. Не заменяет SDEM, не критикует его.
2. **Единая кинетическая модель SP+SD** (`susceptibility/sp_sd_ac/`): Стонер–Вольфарт для частицы, переходы Нееля–Аррениуса, явные координаты и прямая сумма диполь-дипольных полей, переменное поле кГц.
3. **Нейросетевой суррогат PSD-частицы** (`reports/gnn_psd_ensemble_plan.md`): для PSD нет формул, Mumax3 не тянет ансамбль.
4. **Нейросетевой вывод параметров** по χ(T, f) и петлям (`reports/variant_A_plan.md`), где ML реально выигрывает, когда прямая модель дорогая.
5. **Условное распределение поля, зависящее от состояния частицы** (`reports/variant_B_conditional_field_distribution.md`). Расчёт показывает, что поле коррелирует с состоянием частицы, чего SDEM не учитывает.

## Что известно точно, а что нет

- Проверено расчётом: кинетическая модель против Дебая и Стонера–Вольфарта; эффект взаимодействия (4–13% по χ′ при равномерном распределении, 27–35% в кластерах); алгебра c_f и Irs,eff против таблицы 5; корреляция поле-состояние (+0.38σ и −0.98σ).
- **Не проверено:** MCMC на реальных образцах. Нужны: формулы Hc и Hcr с реальными границами размеров для глин, плотность, погрешности измерений. В примере границы состояний условные, вклады фракций оценены грубо.
- **Вопросы к соавторам:** список в конце `reports/sdem_steps_formulas.md` (нормировка v_m в формулах 4–5, границы размеров, применимость ряда Грама–Шарлье при c ≈ 5·10⁻⁴).
- Ссылки в тезисах написаны по памяти, перед подачей сверить выходные данные.

## Запуск

```bash
pip install numpy scipy matplotlib emcee corner
cd /tmp && cp -r /mnt/project-files/sdem_mcmc . && cd sdem_mcmc && python -I sdem_mcmc_classes.py
# кинетическая модель
cd /tmp && cp -r /mnt/project-files/susceptibility/sp_sd_ac . && cd sp_sd_ac && python test_debye.py 1.0 100
```

Запускайте из локальной папки, не из `/mnt/project-files` (на смонтированной папке падают MKL и некоторые библиотеки).
